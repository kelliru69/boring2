# Avatares del menú (Character Select)

Coloca aquí archivos `.tres` de tipo **CharacterData** (apariencia / skin).

Personajes por defecto (sin .tres):
- **Maga** (`char_mage_girl`, skin `mage_girl`)
- **Gato azul** (`char_blue_cat`, skin `blue_cat`)

Las clases de combate (Mage / Swordman) van en `resources/classes/` — ver ClassData.
